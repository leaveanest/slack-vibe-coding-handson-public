# Google Forms 作成手順 — Codex App で自動化

## 1. 前提条件

| 項目 | 確認内容 |
|---|---|
| Google アカウント | Chrome で個人 Google アカウントにログイン済み (会社 Workspace 不可) |
| Codex App | <https://developers.openai.com/codex/app> を開いて操作可能な状態 |
| 参照ファイル | `docs/event-2026-05-19/vote.md` をローカルで開いておく (§3 設問定義を読み取らせる) |
| ブラウザ | Chrome のタブが空いていること (Codex App が新規タブで操作する) |

> ⚠️ Codex App はローカル環境のブラウザを制御して操作します。Chrome が Codex App のアクセスを許可している必要があります。初回は許可ダイアログが出る場合があります。

## ステップ 9: セクションのスキップ案内テキストを追加する

Google Forms のチェックボックス質問 (Q0) ではセクション自動分岐が機能しないため、
セクション 1 (Q0) の後は「案 A の評価」→「案 B の評価」→「案 D の評価」→「案 K の評価」→「全体評価」の順に
**全員が全セクションを通過する設定** を採用する。
各セクション冒頭にスキップ案内テキストを追加することで、触っていないパターンを飛ばせるようにする。

具体的手順:
1. セクション「案 A の評価」を開き、セクション説明欄に「案 A を触った方のみご回答ください。触っていない方はこのセクションをスキップして「次へ」ボタンを押してください。」と入力する
2. セクション「案 B の評価」の説明欄に「案 B を触った方のみご回答ください。触っていない方はこのセクションをスキップして「次へ」ボタンを押してください。」と入力する

## 3. 手動でやる残り作業 (Codex App 実行後)

Codex App がフォームを作成したら、以下を手動で実施してください。

### チェックリスト

- [ ] **短縮 URL を取得する**
  1. フォーム編集画面で「送信」ボタンをクリック
  2. リンクアイコン (チェーンマーク) タブを選択
  3. 「URL を短縮する」チェックボックスを ON にする
  4. 「コピー」ボタンをクリック → `https://forms.gle/XXXXX` 形式の URL を取得
  5. 取得した URL をメモする

- [ ] **QR コードを生成する**
  - 推奨ツール: Chrome の「このページの QR コードを作成」機能 (アドレスバー右端のアイコン、またはメニュー → その他のツール)
  - 代替: <https://qr-code-generator.com/> に短縮 URL を貼り付けて生成
  - 解像度: 300×300 px 以上で PNG 保存
  - スライドの「アンケートページ」に貼り付ける

- [ ] **回答スプレッドシートをリンクする**
  1. フォームの「回答」タブを開く
  2. スプレッドシートアイコン (緑のシートマーク) をクリック
  3. 「新しいスプレッドシートを作成」を選択 → 「作成」
  4. 生成されたスプレッドシートの URL をメモする

- [ ] **Google Meet チャット欄に URL を投稿する準備をする**
  - Google Meet のチャット欄にアンケート URL を貼るメッセージを下書きしておく
  - 当日 93 分時点で投稿 (進行台本 § 参照)

- [ ] **運営内でテスト回答を実施する (最低 2 人)**
  1. フォームの公開 URL (短縮 URL) を運営 Slack に共有
  2. 2 名以上がそれぞれ別パターンを選んで回答する
  3. スプレッドシートにデータが届いていることを確認する
  4. セクションの流れ・スキップ動作が意図通りか確認する
  5. テスト回答は本番前にスプレッドシートから手動で削除する

## 4. Codex App が詰まった場合のフォールバック

Codex App が以下のケースで止まった場合は、人手で対処してください。

### ケース 1: セクション分岐の設定で失敗する

**症状**: Codex App がセクションの「次へ移動先」設定を誤って設定する、または設定できない。

**対処**: 人手でセクション分岐を設定する最小手順:

1. セクション「案 A の評価」の最下部までスクロールする
2. セクション末尾にある「このセクションの後に移動」ドロップダウンをクリックし「次のセクション」になっているか確認する (デフォルトで OK)
3. 各セクション冒頭の説明文を追加するだけでも十分 (方法 A)

### ケース 2: 均等目盛りのラベル設定ができない

**症状**: Q1/Q2/Q4 の均等目盛りで 1 と 5 のラベルが入力できない。

**対処**:

1. 質問を選択した状態で「…」(3点メニュー) → 「必須」の上の設定欄を確認する
2. 均等目盛り質問を選択すると、スケールの下に「ラベル (オプション)」欄が 2 つ表示される
3. 左のラベル欄に「全くそう思わない」、右のラベル欄に「とてもそう思う」と入力する

### ケース 3: フォームが途中で保存されない

**症状**: 編集中に変更が失われた、またはフォームが作成されていない。

**対処**:

1. Google Forms は自動保存のため、手動保存は不要。ページをリロードして確認する
2. ブラウザの戻るボタンは押さず、Google Forms のトップ (<https://forms.google.com/>) から作成済みフォームを探す

### ケース 4: Codex App が Chrome を制御できない

**症状**: Codex App からブラウザが操作されない。

**対処**:

1. Codex App の設定でブラウザアクセス許可が有効か確認する
2. `vote.md` §4 の構築手順に従い Google Forms を開いて直接入力する (人手で 15〜20 分あれば作成可能)

### ケース 5: セクション分岐を自動分岐に切り替えたい場合

**症状**: スキップ案内テキスト方式 (ステップ 9) では操作が煩雑と感じる、または参加者への UX を改善したい。

**対処** (人手で切り替え):

1. Q0 の質問タイプを「チェックボックス」から「ラジオボタン (Multiple choice)」に変更する
   - 制限: 複数パターンを触った参加者はフォームを複数回送信する必要がある
2. Q0 の各選択肢の右端に「セクションに移動」ドロップダウンが表示されるので設定する:
   - 「案 A …」→「案 A の評価」セクションへ移動
   - 「案 B …」→「案 B の評価」セクションへ移動
   - 「案 D …」→「案 D の評価」セクションへ移動
   - 「案 K …」→「案 K の評価」セクションへ移動
3. 各パターンセクション (案 A〜K) の末尾にある「このセクションの後に移動」を「全体評価」に設定する
